
# 📅 VibeCal: The Immersive AI Calendar (MVP)

VibeCal is a smart, aesthetic calendar application that changes its "Vibe" (Theme, Colors, and Animations) automatically based on the time of day. It is designed to make productivity feel immersive and emotional rather than just functional.

## 🚀 Features

* **🌅 Dynamic Time-Based Themes:**
    * **Morning:** Soft Orange Sunrise + Sun Animation.
    * **Afternoon:** Bright Blue Sky + Cloud Animation.
    * **Evening:** Purple Sunset Gradients.
    * **Night:** Deep Blue/Black + Moon Animation.
* **🤖 Social Manager Agent (Demo):** A built-in AI assistant that drafts WhatsApp messages/reminders with one click.
* **☔ Reality Advisor:** Provides smart health and lifestyle tips based on the current time (e.g., UV warnings in the morning, Sleep advice at night).
* **📱 Mobile Responsive:** Built with Streamlit to work seamlessly on mobile and desktop.

## 🛠️ Tech Stack

* **Frontend:** Streamlit (Python)
* **Logic:** Python `datetime` & `pytz` (for Timezone handling)
* **Visuals:** CSS Injection & Lottie Animations (JSON)

## 📦 How to Run Locally

1.  Clone the repository:
    ```bash
    git clone [https://github.com/Shwetam77777/vibecal-mvp.git](https://github.com/Shwetam77777/vibecal-mvp.git)
    ```
2.  Install dependencies:
    ```bash
    pip install streamlit pytz
    ```
3.  Run the app:
    ```bash
    streamlit run streamlit_app.py
    ```
